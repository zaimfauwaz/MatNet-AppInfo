# MatNet AppInfo

A Windows right-click tool that shows whether an .exe, .dll, .msi, .msp, .sys,
.ocx or .rll file is what it claims to be. The trust verdict comes from
Windows' own signature check. Everything else is information to read.

Status: no longer developed. Published as is, with no support, no updates
and no warranty.

Do whatever you like with it: use it, change it, sell it, or call it your own.
